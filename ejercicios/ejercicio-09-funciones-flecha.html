Funciones flecha

Enunciado

Convierte estas funciones a funciones flecha, con la sintaxis más corta posible (sin llaves ni return cuando se pueda). Escribe tú las versiones flecha: function sumar(a, b) { return a + b; } function cuadrado(n) { return n * n; } function saludar() { return "Hola"; } function describir(nombre, edad) { const texto = nombre + " tiene " + edad + " años"; return texto.toUpperCase(); } Muestra por consola sumar(3, 4), cuadrado(5), saludar() y describir("Ana", 20). Después, con const numeros = [1, 2, 3, 4, 5, 6]; usa map y filter con funciones flecha y muestra (con JSON.stringify) los cuadrados de todos los números y solo los números pares.
